# 01 · 产品定位与范围（v0.3）

## 一句话

> 一块好看、会动、能听会看的桌面屏幕。语音助手是可选配件，不是主角。

## 定位转变（相对早期想法）

早期版本把 ThinkOS 设想为「AI 伴侣」，主打语音对话。经评估后降级：

- 单麦克风远场拾音差，1 米外不稳定
- 2GB 内存跑完整语音链路（VAD+STT+LLM+TTS）会与 UI 抢资源
- 这台机器真正的优势是 **屏幕、摄像头、扬声器**

因此产品重心转为「显示 + 音频 + 视觉感知」，语音只保留极少量固定指令。

## 三条主线的权重

| 主线 | 权重 | 具体内容 |
|---|---|---|
| 显示 | 50% | 动画、信息卡片、相册、音乐可视化 |
| 音频 | 30% | 音乐播放、白噪音、音量/均衡、频谱 |
| 视觉 | 20% | 存在感知、低频手势、拍照 |
| 语音 | 可选 | 唤醒词 + 5 个固定指令，默认关闭 |

## 功能范围

### MVP（3–4 周）

**显示**
- 常驻待机：呼吸动画 + 时钟 + 天气
- 全屏相册：Ken Burns 缓慢缩放 + 淡入淡出切换
- 卡片系统：时钟、天气、相册、音乐、通知

**音频**
- 音乐播放（Navidrome 直连，或 Server 上的音乐库流）
- 封面 / 进度 / 播放队列卡片
- 音乐频谱可视化（Canvas 自绘）

**视觉**
- 存在感知：摄像头 1fps 检测人脸，有人亮屏、无人降亮度
- 低频手势：挥手唤醒、左右切卡片、握拳静音

**系统**
- Kiosk 接管（HOME Launcher + 沉浸）
- 开机自启、断线重连、断电恢复

### V1

- 白噪音 / 环境音
- 通知卡片（手机 → Server → 设备）
- 定时拍照 / 延时摄影
- 相册智能轮播

### V2

- 视觉滤镜（镜像、黑白、时间切片）
- 手势自定义
- 语音模块（可选安装，默认关闭）

## 明确不做

- 本地大模型
- WebView 主界面
- 多用户
- 依赖 Home Assistant

（视频通话原在此列，2026-11-04 所有者决定改为要做，见 ADR-047、`43-video-call.md`。）

## 成功标准

| 指标 | 目标 |
|---|---|
| 待机 CPU | < 8% |
| 播放音乐 + 可视化 CPU | < 25% |
| 手势模式 CPU | < 45% |
| 内存峰值 | < 350MB |
| 冷启动 | < 3s |
| 连续运行 | 72 小时不重启 |
| 界面帧率 | 60fps（掉帧时自动降级到 30fps） |

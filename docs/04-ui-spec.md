# 04 · UI 与动效规范

> 关键词：**清亮、扁平、动画优先、远看可读**
> 体验蓝本：iPhone「待机显示」（StandBy），见 ADR-014 与 `03-architecture.md` §2.2
> 设备：8 英寸 LCD，800×1280px，**260dpi（density 1.625）**，观看距离 40–150cm

## 0. 画布

| | 像素 | dp |
|---|---|---|
| 横屏（主形态） | 1280×800 | **788×492** |
| 竖屏 | 800×1280 | **492×788** |

所有尺寸都按上表的 dp 设计。注意画布比直觉小：短边只有 492dp，任何超过 450dp 宽的元素在竖屏下都放不下。

设计原则：

- **横屏优先**：先按横屏设计，竖屏是同一套元素的竖排，而不是另一套界面
- **远看可读**：主信息（时间、温度、曲名）在 1.5 米外能看清；一屏只有一个主角
- **插件无感**：本文定义的颜色、字号、间距、动效都由设备实现，插件只选版式和填内容（ADR-013）；ADR-025 仅开放磁贴底色，其前景仍由 OS 决定

## 1. 主题：白天浅色、夜里深色

主题由**环境光传感器**（VCNL4200 ALS）自动切换，共三档：

| 档位 | 触发 | 观感 |
|---|---|---|
| `LIGHT` 浅色 | 环境光 > 120 lux 持续 30s | 清亮的浅灰白底，白色卡片 |
| `DARK` 深色 | 环境光 < 50 lux 持续 30s | 近黑底，深灰卡片，StandBy 式 |
| `NIGHT` 夜间 | 环境光 < 5 lux 持续 10s（> 15 lux 持续 10s 退出） | 在 DARK 之上整屏红色单色 + 最低亮度 |

切换规则：

- 50–120 lux、5–15 lux 是**滞回区**，在区间内保持当前主题，避免灯光临界时来回跳
- 两次 LIGHT/DARK 切换之间至少间隔 120s
- 用户正在交互（ENGAGED）时推迟切换，回到 AWAKE/AMBIENT 后再执行
- 切换动画：所有颜色 token 在 2s 内插值过渡（§5），不闪、不重建界面
- 传感器失效时：按时间兜底（07:00–19:00 浅色，其余深色），夜间模式关闭
- 阈值、手动锁定主题、关闭夜间模式都是系统级设置（§9），有 APK 内置默认值，可由 Server 随期望状态下发覆盖（`05-protocol.md` §3.2），也可在设备上修改（§10）

### 1.1 颜色 token

所有 View 只引用 token，不写死颜色值。

| token | LIGHT | DARK | 用途 |
|---|---|---|---|
| `bg` | `#F7F8FA` | `#0E0F12` | 全局底色。深色不用纯黑：LCD 背光下纯黑会发灰发亮，近黑反而更干净 |
| `surface` | `#FFFFFF` | `#1B1D22` | 卡片 / 面板 |
| `textPrimary` | `#1B1D21` | `#F2F3F5` | 主文字、时钟数字 |
| `textSecondary` | `#6B7280` | `#8D929B` | 说明、单位 |
| `accent` | `#5B7CFA` | `#7C95FF` | 主色（图形、图标、进度条），最多占画面 10%；深色下提亮以保证对比 |
| `accentText` | `#3F5FE0` | `#7C95FF` | 强调色**文字**（浅色下 `accent` 只有 3.5:1，不能直接用于文字） |
| `warn` | `#F26B5E` | `#FF7A6B` | 提醒图形、错误图标 |
| `warnText` | `#C0392F` | `#FF7A6B` | 警示**文字** |
| `divider` | `#E8EAEF` | `#2A2D33` | 1dp 分隔线 |
| `shadow` | 2dp 偏移、8% 黑 | 无阴影 | 深色下用 `surface` 与 `bg` 的明度差区分层次 |

`mood`（插件给的主色，例如照片或封面的主色）会按当前主题重新映射明度：LIGHT 下映射为高明度低饱和的背景染色，DARK 下映射为低明度的光晕，避免出现刺眼的大色块。

### 1.2 夜间模式

- 实现：Stage 根层的 `ColorMatrixColorFilter`，把画面亮度映射为红色单色（`#000000` → `#FF3B2F`），见 `03-architecture.md` §3.4
- 只在 DARK 之上叠加，所以画面大部分是黑底，红色只出现在数字和图标上
- 背光压到最低档；照片页在夜间模式下自动切回时钟页（红色照片没有观赏价值）
- 例外：`level=urgent` 的通知不受红色滤镜影响

### 1.3 规则

- **禁止**渐变背景、毛玻璃、拟物阴影、多层嵌套卡片
- 强调色同时最多出现 2 种
- 文字对比度 ≥ 4.5:1，图形 ≥ 3:1（两套主题均已按 WCAG 公式校核：浅色 `textSecondary` 4.55、`accentText` 5.04、`warnText` 5.11；深色 `textSecondary` 5.39、`accent` 6.10、`warn` 6.62，均以较差的底色计）

## 2. 排版

字体：系统默认（Roboto + Noto Sans CJK）。数字一律开**等宽数字**（`Paint.setFontFeatureSettings("tnum")`），避免走秒时左右抖动；不用 `monospace` 字体。

| 层级 | 字号 | 字重 | 用途 |
|---|---|---|---|
| 表盘数字 | 按画布比例，见 §4.3 | Light（`sans-serif-light`） | 全屏时钟 |
| 卡片主数据 | 72sp | Light | 栈里卡片的大数字（温度、时间） |
| 页面标题 / 曲名 | 32sp | Medium | — |
| 卡片副标题 | 22sp | Regular | 天气描述、艺术家 |
| 正文 | 18sp | Regular | 列表条目 |
| 辅助说明 | 14sp | Regular | 角标、时间戳（最小字号） |

- 行高 = 字号 × 1.3（大数字 × 1.0）
- 浅色与深色使用同一套字号字重；深色下文字视觉上偏粗，字重不再加重

## 4. 页面版式

版式由设备实现，插件只选用（`03-architecture.md` §3.6）。左右滑切页面，上下滑切变体；页面底部（竖屏为右侧）显示变体指示点，2 秒后淡出。

### 4.1 `stacks` —— 小组件视图（`home.main`）

```
横屏 788×492dp                               竖屏 492×788dp
┌──────────────────────────────────────┐     ┌──────────────────────┐
│ ┌────────────────┐ ┌────────────────┐ │     │ ┌──────────────────┐ │
│ │                │ │                │•│     │ │                  │•│
│ │   左栈卡片      │ │   右栈卡片      │•│     │ │     上栈卡片      │ │
│ │   366×452      │ │   366×452      │ │     │ │     452×366      │ │
│ │                │ │                │ │     │ └──────────────────┘ │
│ └────────────────┘ └────────────────┘ │     │ ┌──────────────────┐ │
└──────────────────────────────────────┘     │ │     下栈卡片      │•│
                                             │ │     452×366      │ │
                                             │ └──────────────────┘ │
                                             └──────────────────────┘
```

- 两个栈互相独立，各自上下滑翻卡；栈边缘显示竖向指示点
- 智能轮换：用户 5 分钟内没有手动翻动时，栈按插件给的相关度自动转到最相关的卡片
- 卡片模板 `glance` / `media` / `list` / `photo` / `stack` 在两种方向下都要能放进 366×366 的最小安全区
- 背景呼吸场在两个栈之间的缝隙和四周可见

### 4.2 `slideshow` —— 照片视图（`gallery.slideshow`）

- 设备完整适配照片，不永久裁掉内容；超出屏幕的轴缓慢平移，扫过两端后才轮播。关闭平移或减少动画时整张缩放，纯色留边（ADR-024）
- 上滑看更早的图片，下滑返回更新的图片；手动浏览到首尾回弹，时间固定在叠层。自动轮播仍循环；点击下一张、长按设置、左右翻页
- 平移：每张随机方向，原生连续缓入缓出，默认至少 12 秒、上限 45dp/s，扫完停留；不再用 5fps 逐步挪坐标
- 切换：默认交叉淡入 800ms，可选 slide/zoom/random；无持续放大裁切。停留、转场、平移速度与字幕时长走插件设置 schema
- 角落叠时间（StandBy 风格）：横竖屏均固定右上角，与屏幕边缘保持 24dp，数字靠右对齐，不再在宽容器内居中或单独漂移；照片专用 float 时钟统一白字，1.25dp 窄黑色描边（约 73% 不透明度），包含 AM/PM 与未校时的 --:--，在 LIGHT/DARK 和亮照片上都可读；其它表盘保持原样
- 不显示进度条和圆点；默认微软每日一图，可在设置选择本地目录或两者混合，相簿变体仍暂缓。点击下一张，长按打开相册设置
- 说明集中在底部同一文字组：边距 24dp，标题 18sp Medium（最多两行），下方 8dp 间距接 12sp 署名；署名完整换行。竖屏使用可用宽度，横屏最多 560dp，保持自然行长。标题按设置显示/淡出，署名常驻；关闭字幕也保留署名。状态提示紧靠文字组上方，与其对齐，不覆盖署名
- 夜间模式下不显示本页（§1.2）

### 4.3 `focus` —— 时钟视图（`clock.face`）

一个主角铺满整屏，上下滑切换表盘变体：

| 变体 | 横屏 | 竖屏 |
|---|---|---|
| `digital` | `09:41` 一行，数字高度 ≈ 短边 × 0.55（≈ 270dp） | 时、分上下两行，每行数字高度 ≈ 短边 × 0.5 |
| `analog` | 表盘直径 = 短边 − 40dp（452dp），居中 | 同左 |
| `solar` | 太阳沿弧线运行的日光表，时间在弧下方 | 弧线改为竖向 |
| `world` | 2–4 个城市的小表盘并排 | 两列网格 |
| `float` | 大号数字缓慢漂浮（自带防残影） | 同左 |

- 数字变化用竖向滚动过渡（260ms），冒号以 2 秒周期轻微呼吸
- 日期、天气等次要信息只占一行，字号 22sp

### 4.5 `list`

标题 + 列表（日程、播放队列等）。条目 18sp，行高 56dp，入场时逐条错开 30ms。

### 4.6 通知

| Attention | 形态 |
|---|---|
| AMBIENT / ASLEEP | 居中大图标（96dp）+ 标题（32sp），先提升到 AWAKE 亮度，6 秒后缩小收起 |
| AWAKE / ENGAGED | 顶部滑入卡片，宽 = 画布宽 − 40dp（横屏最大 560dp），停留 8 秒或点击消失 |

- 提示音音量比当前媒体音量低约 6dB，播放音乐时先压低音乐

## 5. 动效规范

| 场景 | 动画 | 时长 | 缓动 |
|---|---|---|---|
| 待机呼吸 | 背景呼吸场缩放 0.98 ↔ 1.02 + 微光 | 4s 循环 | ease-in-out |
| 唤醒（有人走近） | 中心波纹扩散 + 回弹 + 卡片依次浮现 | 400ms | ease-out |
| 离开（变暗） | 卡片依次沉下淡出 + 亮度缓降 | 2s | ease-in-out |
| 左右翻页 | 跟手位移 + 松手后交叉淡入，元素错开入场 | 320ms | ease-out |
| 上下切变体 / 翻栈 | 跟手竖向位移，松手后弹簧吸附到位 | ≈ 350ms | 弹簧（阻尼 0.85） |
| 栈自动轮换 | 竖向滑动 + 淡入 | 500ms | ease-in-out |
| 卡片出现 | 上移 16dp + 淡入 | 260ms | ease-out |
| 数字更新 | 竖向滚动 | 260ms | ease-out |
| 实时活动接管 | 卡片从所在位置放大到全屏（共享元素） | 450ms | ease-out |
| 通知（顶部） | 顶部滑入 + 轻微回弹 | 350ms | overshoot |
| 通知（居中大图标） | 缩放 0.8 → 1 + 淡入，收起时缩回 | 400ms | ease-out |
| 主题切换（浅 ↔ 深） | 全部颜色 token 插值 | 2s | ease-in-out |
| 进出夜间模式 | 颜色矩阵插值 + 亮度缓降 | 1.5s | ease-in-out |
| 手势确认 | 对应方向屏幕边缘一道轻光 | 240ms | ease-out |
| 长按反馈 | 按住 0.3s 起页面缓慢缩小到 0.98，到 0.6s 触发；中途松手则弹回 | 300ms | ease-out |
| 进入 / 退出设置页 | 原页面缩小到 0.96 并淡出，设置页淡入 + 8dp 上移；退出反向 | 320ms | ease-out |
| 设置控件 | 开关滑动 160ms；单选就地展开 / 收起 200ms；数值变化不做过渡 | 160–200ms | ease-out |
| 语音聆听（可选） | 底部聆听条，随音量起伏 | 实时 | — |

统一常量集中在 `anim/Motion.kt`，不允许散落魔数。事件与动画的完整映射见 `03-architecture.md` §3.7.5。

## 6. 性能预算（硬约束）

| 指标 | 上限 |
|---|---|
| 单帧绘制 | 12ms |
| 同时播放的 Lottie | 3 个 |
| 单个 Lottie 图层数 | 40 |
| 同时存在的大图 | 2 张（≤ 800×1280） |
| 内存峰值 | 350MB |

**强制要求**
- 循环动画的 View 开 `setLayerType(LAYER_TYPE_HARDWARE, null)`
- 不用 `blur`、不用大面积 `shadow`、不嵌套 alpha 动画
- 主题切换只插值颜色、不重建 View；夜间滤镜只用根层的一个 `ColorMatrixColorFilter`
- 掉帧自动降级：连续 3 秒 < 45fps → 降低动画帧率 / 减少频谱条数

## 7. 横竖屏

- 横屏为主形态，竖屏是同一套元素的竖排（各版式的竖屏布局见 §4）
- 用代码里的 `LayoutSpec` 计算布局，不使用 `layout-land` 的重建机制
- 旋转时**不重放入场动画**，元素用 FLIP 从旧位置过渡到新位置（320ms）
- 方向锁定是系统级设置 `display.orientation`（§9）

## 8. 无障碍与可读性

- 最小字号 14sp；主信息在 1.5 米外可读
- 两套主题对比度均 ≥ 4.5:1
- 所有可点击区域 ≥ 48dp
- 动画尊重系统「减少动画」设置（若可读取则降低帧率）

## 9. 系统级设置（ADR-017）

系统级设置由 OS 自己声明，schema 放在 `shared/schema/settings/system.json`，格式与插件的页面级设置完全相同（`06-plugins.md` §11.1）。设备端代码一律按这些 key 读取，**不要把阈值和开关写死在代码里**；默认值与现有实现一致。

位置设置（ADR-021）包含 `location.mode/name/latitude/longitude/elevation/timezone/search_url`。自动模式的坐标来自设备时区的代表城市，界面明确说明精度；地点选择器可搜索城市、区县并显示行政层级，始终提供离线手填入口。选中地点以一次原子设置提交切换到手动模式。查询中、无结果、失败及数据来源均有本地化文案；搜索 URL 也由此 schema 管理。

| key | 类型 | 取值 / 范围 | 默认 | 说明 |
|---|---|---|---|---|
| `theme.mode` | choice | `auto` 自动（环境光）/ `light` 始终浅色 / `dark` 始终深色 | `auto` | 固定后不再按环境光在 LIGHT / DARK 间切换；传感器失效时的 07:00–19:00 兜底只在 `auto` 下生效 |
| `theme.night` | bool | — | 开 | 关则永不进入红色夜间模式；与 `theme.mode` 无关 |
| `theme.dark_below_lux` | number | 10–200，步长 5，lux | 50 | 浅色 → 深色 |
| `theme.light_above_lux` | number | 50–1000，步长 10，lux | 120 | 深色 → 浅色，必须大于 `dark_below_lux` |
| `theme.night_below_lux` | number | 1–20，lux | 5 | 进入夜间模式 |
| `theme.night_above_lux` | number | 5–50，lux | 15 | 退出夜间模式，必须大于 `night_below_lux` |
| `display.orientation` | choice | `auto` 跟随 / `landscape` 锁定横屏 / `portrait` 锁定竖屏 | `auto` | 立即生效，不重建 Activity |
| `display.brightness_max` | number | 20–100，步长 5，% | 85 | AWAKE / ENGAGED 亮度；AMBIENT 约为其 47%，ASLEEP 固定最低（3%） |
| `attention.awake_to_ambient_s` | number | 30–600，步长 10，秒 | 120 | 有人但没在看多久后进入 AMBIENT |
| `attention.to_asleep_s` | number | 60–1800，步长 30，秒 | 180 | 无人多久后进入 ASLEEP |
| `attention.engaged_idle_s` | number | 5–60，步长 5，秒 | 15 | 无交互多久后退出 ENGAGED |
| `attention.ambient_page_after_s` | number | 60–1800，步长 30，秒 | 300 | AMBIENT 持续多久后切到 `ambient` 角色页面 |
| `server.url` | text | 空 = 通过 mDNS 自动发现 | 空 | 固定 Server 地址（`05-protocol.md` §2） |
| `server.token` | text（`secret`） | — | 空 | 共享配对 token；V1 改为配对码 |
| `kiosk.lock` | bool | — | 开 | 锁定系统界面：状态栏下拉、Home、Recents、系统手势（Lock Task，需 Device Owner；非 Device Owner 时只有沉浸式 + 看门狗）。关闭后立即退出锁定，是设备上自己的退出路径 |
| `time.ntp_servers` | text | 逗号分隔的主机名 | 4 个 `*.pool.ntp.org` | App 自己的校时来源：每个名字解析出的全部地址都问一遍，取往返最短的。**设置页不显示**，可由 Server 下发 |
| `time.sync_hour` | number | 0–23，小时 | 4 | 每天校时的时刻（本地时间，另加 0–10 分钟随机，错开 pool 负载）。设置页不显示，可由 Server 下发 |
| `voice.enabled` | bool | — | 关 | 语音模块可用前（M4）不在设置页显示 |

- 跨字段约束（两对 lux 阈值）违反时拒绝写入并提示原因
- 变化立即生效：主题阈值与注意力计时由策略对象在下一次采样时读取新值，方向与亮度立即应用；主题切换按 §1 的 2 秒颜色插值过渡
- **不在设备设置里**的东西：页面顺序、首页两栈放哪些卡片、安装哪些插件、照片集——它们是部署配置，由 Server 管理（`06-plugins.md` §8、§12）

## 10. 设置页（`form` 版式）

设置页是 `settings` 插件的页面（`06-plugins.md` §11.3），版式 `form` 由 OS 提供，样式遵循本文其它章节（token、字号、间距、夜间滤镜都自动生效）。

```
横屏 788×492dp                              竖屏 492×788dp
┌──────────────────────────────────────┐    ┌──────────────────────┐
│  天气                          完成  │    │ 天气            完成 │
│ ──────────────────────────────────── │    │ ──────────────────── │
│  城市                    Hong Kong › │    │ 城市      Hong Kong › │
│  ● 纬度            ─────●──── 22.3  │    │ ● 纬度   ───●── 22.3 │
│  温度单位                      摄氏 ›│    │ 温度单位         摄氏 ›│
│  系统设置 ›                          │    │ 系统设置 ›           │
└──────────────────────────────────────┘    └──────────────────────┘
```

- 单列，横屏居中、最大宽 560dp，竖屏左右各 20dp；超出屏幕高度时竖向滚动。标题 32sp Medium，右侧“完成”热区 ≥ 48dp
- 最小行高 56dp；分组标题 14sp 次文字色；行标签 18sp，最多两行；右侧当前值 14sp 次文字色，占用不超过可用文字区域的一半，过长省略。帮助文字 `help` 用 14sp 放在标签下方，按宽度完整换行，行高随内容增长；整行的无障碍描述包含说明
- 控件：
  - `bool` → 开关（52×32dp），点整行切换；无障碍节点提供开关角色与选中状态
  - `choice` → 行尾显示当前值和 ›，点击后**就地展开**选项列表（不弹对话框），选中即收起
  - `number` → 行内滑块（轨道 ≥ 200dp）+ 两侧 48dp 的 −/+ 按钮，右侧显示数值与单位；横向拖动时只在松手时提交，纵向起手交给页面滚动，取消手势恢复已提交值
  - `text` → 行尾显示值（过长截断，`secret` 显示为 ••••）；点击进入编辑，若设备没有输入法则为只读（见 `06-plugins.md` §11.3）
- 被设备修改过的项在标签前显示 accent 色小圆点（●）；圆点位于 48×48dp 的点击区域内，点按重置该项，无障碍描述包含字段名
- 提交失败时控件回弹到原值，并在该行下方用 `warnText` 色显示一行原因，3 秒后以 120ms 淡出；系统关闭动画时直接清除。再次失败重新计时，成功修改、重置、切换设置作用域、离开页面或切换语言均取消旧提示计时，避免旧回调干扰新页面
- 入口：长按页面（反馈见 §5）。页面或卡片所属插件没有设置项时直接显示系统设置；列表末尾有“系统设置 ›”，系统设置页末尾有“其它插件 ›”进入有设置项的插件列表
- 退出：点“完成”、30 秒无操作或按 Home 键；设置页打开期间保持 ENGAGED 档，不触发变暗。原生输入框中的打字与按键也算操作；Home 退出时丢弃未保存的输入草稿
- 行数有限（以系统 schema 为准，插件 ≤ 32 项），直接创建全部行；城市与时区搜索结果用原生列表复用行

## 磁贴（API 4 / ADR-025）

固定网格横屏 6×4、竖屏 4×6；外边距 20dp，间距 8dp，磁贴直角 0dp、内边距 12dp。尺寸 small/medium/wide/large 对应 1×1/2×2/4×2/4×4，内容密度由 OS 固定；所有文字单行省略。背景按引用 color > tile color > accent，前景自动黑白，颜色变化按 Motion.NUMBER 插值，不重建 View。夜间根层滤镜统一处理。系统设置 tiles.live 默认 true，tiles.interval 默认 8 秒（5–60、步长 1），各语言同名字段由 shared schema 生成。

用户补充（2026-10-31）：以 Windows Phone / Windows 8.1 的 Metro 磁贴为参照。磁贴必须直角、平面、无阴影；网格基础单元保持正方形；信息以大号轻字重数字为主、标签锚定底部起始侧、纯色留白，不沿用普通圆角卡片的排版。RTL 镜像网格和内容。参考微软 [Windows Phone 设计建议](https://blogs.windows.com/windowsdeveloper/2013/01/18/8-tips-for-designing-windows-phone-apps/) 与 [Windows/Phone 8.1 磁贴模板目录](https://learn.microsoft.com/en-us/previous-versions/windows/apps/hh761491(v=win.10))。使用现有 Android 字体，不分发 Segoe。当前沿用 Windows 8.1 的垂直 peek 方向，不采用 Phone 的 3D 翻转。

真机发现夜间红色矩阵会压低中灰底的对比度。磁贴按合成后的颜色选择黑白前景；两者都低于 4.5:1 时，仅在夜间把底色向最近的可读亮/暗端补偿。浅色/深色完全保留插件底色；夜间仍经过统一根层滤镜。

# 04 · UI 与动效规范

> 关键词：**清亮、扁平、动画优先、远看可读**
> 体验蓝本：iPhone「待机显示」（StandBy），见 ADR-014 与 `03-architecture.md` §2.2
> 设备：8 英寸 LCD，800×1280px，**260dpi（density 1.625）**，观看距离 40–150cm

## 0. 画布

| | 像素 | dp |
|---|---|---|
| 横屏（主形态） | 1280×800 | **788×492** |
| 竖屏 | 800×1280 | **492×788** |

所有尺寸都按上表的 dp 设计。注意画布比直觉小：短边只有 492dp，任何超过 450dp 宽的元素在竖屏下都放不下。

设计原则：

- **横屏优先**：先按横屏设计，竖屏是同一套元素的竖排，而不是另一套界面
- **远看可读**：主信息（时间、温度、曲名）在 1.5 米外能看清；一屏只有一个主角
- **插件无感**：本文定义的颜色、字号、间距、动效都由设备实现，插件只选版式和填内容（ADR-013）；ADR-025 仅开放磁贴底色，其前景仍由 OS 决定

## 1. 主题：白天浅色、夜里深色

白天的 LIGHT / DARK 按 `theme.mode` 使用环境光、日出日落或固定主题；模式决策器独立控制红移与睡眠（`45-modes.md`）。主题仍保留三档：

| 档位 | 触发 | 观感 |
|---|---|---|
| `LIGHT` 浅色 | 环境光 > 120 lux 持续 30s | 清亮的浅灰白底，白色卡片 |
| `DARK` 深色 | 环境光 < 50 lux 持续 30s | 近黑底，深灰卡片，StandBy 式 |
| `NIGHT` 红移 | `redshift.trigger` 的日落、环境光或固定时间规则，或手动切换 | 在 DARK 之上整屏红色单色 + 最低亮度 |

切换规则：

- 50–120 lux、5–15 lux 是**滞回区**，在区间内保持当前主题，避免灯光临界时来回跳
- 两次 LIGHT/DARK 切换之间至少间隔 120s
- 用户正在交互（ENGAGED）时推迟自动切换，最长读 `mode.engaged_delay_s`（默认600秒）；睡眠开始另读 `sleep.start_delay_s`
- 切换动画：所有颜色 token 在 2s 内插值过渡（§5），不闪、不重建界面
- 传感器失效时：白天主题按 `theme.fallback_start/end` 兜底（默认07:00–19:00浅色，其余深色）；红移有有效日落或固定窗口时按窗口进入，无有效窗口时不进入
- 阈值、手动锁定主题、红移触发与睡眠时间表都是系统级设置（§9），有 APK 内置默认值，可由 Server 随期望状态下发覆盖（`05-protocol.md` §3.2），也可在设备上修改（§10）

### 1.1 颜色 token

所有 View 只引用 token，不写死颜色值。

| token | LIGHT | DARK | 用途 |
|---|---|---|---|
| `bg` | `#F7F8FA` | `#0E0F12` | 全局底色。深色不用纯黑：LCD 背光下纯黑会发灰发亮，近黑反而更干净 |
| `surface` | `#FFFFFF` | `#1B1D22` | 卡片 / 面板 |
| `textPrimary` | `#1B1D21` | `#F2F3F5` | 主文字、时钟数字 |
| `textSecondary` | `#6B7280` | `#8D929B` | 说明、单位 |
| `accent` | `#5B7CFA` | `#7C95FF` | 主色（图形、图标、进度条），最多占画面 10%；深色下提亮以保证对比 |
| `accentText` | `#3F5FE0` | `#7C95FF` | 强调色**文字**（浅色下 `accent` 只有 3.5:1，不能直接用于文字） |
| `warn` | `#F26B5E` | `#FF7A6B` | 提醒图形、错误图标 |
| `warnText` | `#C0392F` | `#FF7A6B` | 警示**文字** |
| `divider` | `#E8EAEF` | `#2A2D33` | 必要描边，1 物理像素；列表不画分隔线 |
| `shadow` | 仅照片、视频上的文字 | 同左 | 普通容器不画阴影；Aero 见 ADR-026 例外 |

`mood`（插件给的主色，例如照片或封面的主色）会按当前主题重新映射明度：LIGHT 下映射为高明度低饱和的背景染色，DARK 下映射为低明度的光晕，避免出现刺眼的大色块。

### 1.2 红移

> 名称统一为“红移”，内部 `Theme.NIGHT` 保留；旧 `theme.night` 是隐藏兼容键，按层迁入 `redshift.trigger`。日落日出、手动切换与睡眠规则见 `45-modes.md`（ADR-048）。

- 实现：Stage 根层的 `ColorMatrixColorFilter`，把画面亮度映射为红色单色（`#000000` → `#FF3B2F`），见 `03-architecture.md` §3.4
- 只在 DARK 之上叠加，所以画面大部分是黑底，红色只出现在数字和图标上
- 背光压到最低档；照片页在红移下自动切回时钟页（红色照片没有观赏价值）
- 例外：`level=urgent` 的通知不受红色滤镜影响

睡眠当前已接逻辑模式、静音和播放/投屏拒绝，画面暂沿用 `NIGHT`，窗口亮度仍不低于3%；这不是全黑效果。背光0、双击偷看与结束睡眠画面须等MODE0人工验证后实现，不能用逻辑 `sleep` 状态当作黑屏验收。

### 1.3 规则

- **禁止**渐变背景、毛玻璃、拟物阴影、多层嵌套卡片
- 强调色同时最多出现 2 种
- 文字对比度 ≥ 4.5:1，图形 ≥ 3:1（两套主题均已按 WCAG 公式校核：浅色 `textSecondary` 4.55、`accentText` 5.04、`warnText` 5.11；深色 `textSecondary` 5.39、`accent` 6.10、`warn` 6.62，均以较差的底色计）

## 2. 排版

字体：系统默认（Roboto + Noto Sans CJK）。数字一律开**等宽数字**（`Paint.setFontFeatureSettings("tnum")`），避免走秒时左右抖动；不用 `monospace` 字体。

| 层级 | 字号 | 字重 | 用途 |
|---|---|---|---|
| 表盘数字 | 按画布比例，见 §4.3 | Light（`sans-serif-light`） | 全屏时钟 |
| 卡片主数据 | 72sp | Light | 栈里卡片的大数字（温度、时间） |
| 页面标题 / 曲名 | 32sp | Medium | — |
| 正文 | 18sp | Regular | 列表条目 |
| 辅助说明 | 14sp | Regular | 角标、时间戳（最小字号） |

- 只有 72、32、18、14sp 四档，使用 `TextScale`；放不下时降档或省略，hero 最大 72sp。时钟表盘、图标字形和视频字幕例外（ADR-044）
- 行高 = 字号 × 1.3（大数字 × 1.0）
- 浅色与深色使用同一套字号字重；深色下文字视觉上偏粗，字重不再加重

## 3. 间距与形状

| 项 | 值 |
|---|---|
| 屏幕外边距 | 20dp |
| 卡片间距 | 16dp |
| 卡片内边距 | 24dp |
| 卡片圆角 | 32dp（栈卡片） / 20dp（小组件） |
| 图标描边 | 2dp，圆头端点 |
| 最小点击区域 | 48dp |

线宽统一由 `Stroke` 提供：描边 1 物理像素，图标/曲线 2dp，进度/滑块轨道 4dp。时钟表盘、Aero 和字幕描边例外。列表不画分隔线，容器不画外框；图表只有一条线和一块填充，无基线、网格或坐标轴。内圆角 = max(0，外圆角 − 内边距)，具体嵌套核对如下（Aero 除外）：

| 外层 / 内层 | 外圆角 | 内边距 | 内圆角 |
|---|---|---|---|
| Tabs 轨道 / 选中项 | 24dp | 4dp | 20dp |
| 栈卡片 / 图片或相册预览 | 32dp | 24dp | 8dp，OS outline 裁切 |
| 栈卡片 / nowplaying 封面 | 32dp | 24dp | 8dp |
| 操作栏底部 / 内容 | 32dp | 水平 24dp、底部 20dp | 内容不画第二层容器；靠边的封面 8dp，且不进入底角区域 |
| 有底色栈卡片 / 列表高亮 | 32dp | 24dp | 8dp |

整页播放封面、独立列表高亮与圆形功能按钮没有外层同心容器；栈翻页的 32dp 蒙版保持原值。

## 4. 页面版式

版式由设备实现，插件只选用（`03-architecture.md` §3.6）。左右滑切页面，上下滑切变体；页面底部（竖屏为右侧）显示变体指示点，2 秒后淡出。**应用、接管页和设置页不在翻页序列里**（ADR-040）：左右滑属于它们自己，不画翻页指示点；退出靠返回——从最左缘起手向右滑，或 Back 键。栈里没有东西时，最左缘的右滑仍然是翻页。打开应用时磁贴翻转，见 `33-apps-and-back.md` §5。

### 4.1 `stacks` —— 小组件视图（`home.main`）

```
横屏 788×492dp                               竖屏 492×788dp
┌──────────────────────────────────────┐     ┌──────────────────────┐
│ ┌────────────────┐ ┌────────────────┐ │     │ ┌──────────────────┐ │
│ │                │ │                │•│     │ │                  │•│
│ │   左栈卡片      │ │   右栈卡片      │•│     │ │     上栈卡片      │ │
│ │   366×452      │ │   366×452      │ │     │ │     452×366      │ │
│ │                │ │                │ │     │ └──────────────────┘ │
│ └────────────────┘ └────────────────┘ │     │ ┌──────────────────┐ │
└──────────────────────────────────────┘     │ │     下栈卡片      │•│
                                             │ │     452×366      │ │
                                             │ └──────────────────┘ │
                                             └──────────────────────┘
```

- 两个栈互相独立，各自上下滑翻卡；栈边缘显示竖向指示点
- 卡片被拖动或回弹时，只在自己的栈里滑动：栈是一个圆角窗口（和卡片同样的 32dp 圆角），卡片滑出的部分被它裁掉，不会盖住另一个栈，也不会溢出到屏幕边缘；静止时不做任何额外处理。实现与原因见 `10-known-issues.md` §4
- 智能轮换：用户 5 分钟内没有手动翻动时，栈按插件给的相关度自动转到最相关的卡片
- 卡片模板 `glance` / `media` / `list` / `photo` / `stack` 在两种方向下都要能放进 366×366 的最小安全区
- 背景呼吸场在两个栈之间的缝隙和四周可见

### 4.2 `slideshow` —— 照片视图（`gallery.slideshow`）

- 设备完整适配照片，不永久裁掉内容；超出屏幕的轴缓慢平移，扫过两端后才轮播。关闭平移或减少动画时整张缩放，纯色留边（ADR-024）
- 上滑看更早的图片，下滑返回更新的图片；手动浏览到首尾回弹，时间固定在叠层。自动轮播仍循环；点击下一张、长按设置、左右翻页
- 平移：每张随机方向，原生连续缓入缓出，默认至少 12 秒、上限 45dp/s，扫完停留；不再用 5fps 逐步挪坐标
- 切换：默认交叉淡入 800ms，可选 slide/zoom/random；无持续放大裁切。停留、转场、平移速度与字幕时长走插件设置 schema
- 角落叠时间（StandBy 风格）：横竖屏均固定右上角，与屏幕边缘保持 24dp，数字靠右对齐，不再在宽容器内居中或单独漂移；照片专用 float 时钟统一白字，1.25dp 窄黑色描边（约 73% 不透明度），包含 AM/PM 与未校时的 --:--，在 LIGHT/DARK 和亮照片上都可读；其它表盘保持原样
- 不显示进度条和圆点；默认微软每日一图，可在设置选择本地目录或两者混合，相簿变体仍暂缓。点击下一张，长按打开相册设置
- 说明集中在底部同一文字组：边距 24dp，标题 18sp Medium（最多两行），下方 8dp 间距接 14sp 署名；署名完整换行。竖屏使用可用宽度，横屏最多 560dp，保持自然行长。标题按设置显示/淡出，署名常驻；关闭字幕也保留署名。状态提示紧靠文字组上方，与其对齐，不覆盖署名
- 红移下不显示本页（§1.2）

### 4.3 `focus` —— 时钟视图（`clock.face`）

一个主角铺满整屏，上下滑切换表盘变体：

| 变体 | 横屏 | 竖屏 |
|---|---|---|
| `digital` | `09:41` 一行，数字高度 ≈ 短边 × 0.55（≈ 270dp） | 时、分上下两行，每行数字高度 ≈ 短边 × 0.5 |
| `analog` | 表盘直径 = 短边 − 40dp（452dp），居中 | 同左 |
| `solar` | 太阳沿弧线运行的日光表，时间在弧下方 | 弧线改为竖向 |
| `world` | 2–4 个城市的小表盘并排 | 两列网格 |
| `float` | 大号数字缓慢漂浮（自带防残影） | 同左 |

- 数字变化用竖向滚动过渡（260ms），冒号以 2 秒周期轻微呼吸
- 日期、天气等次要信息只占一行，字号 18sp

### 4.5 `list`

标题 + 列表（日程、播放队列等）。条目 18sp，行高 56dp，入场时逐条错开 30ms。

### 4.6 通知

| Attention | 形态 |
|---|---|
| AMBIENT / ASLEEP | 居中大图标（96dp）+ 标题（32sp），先提升到 AWAKE 亮度，6 秒后缩小收起 |
| AWAKE / ENGAGED | 顶部滑入卡片，宽 = 画布宽 − 40dp（横屏最大 560dp），停留 8 秒或点击消失 |

- 提示音音量比当前媒体音量低约 6dB，播放音乐时先压低音乐

## 5. 动效规范

| 场景 | 动画 | 时长 | 缓动 |
|---|---|---|---|
| 待机呼吸 | 背景呼吸场缩放 0.98 ↔ 1.02 + 微光 | 4s 循环 | ease-in-out |
| 唤醒（有人走近） | 中心波纹扩散 + 回弹 + 卡片依次浮现 | 400ms | ease-out |
| 离开（变暗） | 卡片依次沉下淡出 + 亮度缓降 | 2s | ease-in-out |
| 左右翻页 | 跟手位移 + 松手后交叉淡入，元素错开入场 | 320ms | ease-out |
| 上下切变体 / 翻栈 | 跟手竖向位移，松手后弹簧吸附到位 | ≈ 350ms | 弹簧（阻尼 0.85） |
| 栈自动轮换 | 竖向滑动 + 淡入 | 500ms | ease-in-out |
| 卡片出现 | 上移 16dp + 淡入 | 260ms | ease-out |
| 数字更新 | 竖向滚动 | 260ms | ease-out |
| 实时活动接管 | 卡片从所在位置放大到全屏（共享元素） | 450ms | ease-out |
| 通知（顶部） | 顶部滑入 + 轻微回弹 | 350ms | overshoot |
| 通知（居中大图标） | 缩放 0.8 → 1 + 淡入，收起时缩回 | 400ms | ease-out |
| 主题切换（浅 ↔ 深） | 全部颜色 token 插值 | 2s | ease-in-out |
| 进出红移 | 颜色矩阵插值 + 亮度缓降 | 1.5s | ease-in-out |
| 手势确认 | 对应方向屏幕边缘一道轻光 | 240ms | ease-out |
| 长按反馈 | 按住 0.3s 起页面缓慢缩小到 0.98，到 0.6s 触发；中途松手则弹回 | 300ms | ease-out |
| 进入 / 退出设置页 | 原页面缩小到 0.96 并淡出，设置页淡入 + 8dp 上移；退出反向 | 320ms | ease-out |
| 设置控件 | 开关滑动 160ms；单选就地展开 / 收起 200ms；数值变化不做过渡 | 160–200ms | ease-out |
| 语音聆听（可选） | 底部聆听条，随音量起伏 | 实时 | — |

统一常量集中在 `anim/Motion.kt`，不允许散落魔数。事件与动画的完整映射见 `03-architecture.md` §3.7.5。

## 6. 性能预算（硬约束）

| 指标 | 上限 |
|---|---|
| 单帧绘制 | 12ms |
| 同时播放的 Lottie（计划，当前未引入） | 3 个 |
| 单个 Lottie 图层数（计划） | 40 |
| 同时存在的大图 | 2 张（≤ 800×1280） |
| 内存峰值 | 350MB |

**强制要求**
- 循环动画的 View 开 `setLayerType(LAYER_TYPE_HARDWARE, null)`
- 不用 `blur`、不用大面积 `shadow`、不嵌套 alpha 动画
- 主题切换只插值颜色、不重建 View；夜间滤镜只用根层的一个 `ColorMatrixColorFilter`
- 掉帧自动降级：连续 3 秒 < 45fps → 降低动画帧率 / 减少频谱条数

## 7. 横竖屏

- 横屏为主形态，竖屏是同一套元素的竖排（各版式的竖屏布局见 §4）
- 用代码里的 `LayoutSpec` 计算布局，不使用 `layout-land` 的重建机制
- 旋转时**不重放入场动画**，元素用 FLIP 从旧位置过渡到新位置（320ms）
- 方向锁定是系统级设置 `display.orientation`（§9）

## 8. 无障碍与可读性

- 最小字号 14sp；主信息在 1.5 米外可读
- 两套主题对比度均 ≥ 4.5:1
- 所有可点击区域 ≥ 48dp
- 动画尊重系统「减少动画」设置（若可读取则降低帧率）

## 9. 系统级设置（ADR-017）

系统级设置由 OS 自己声明，schema 放在 `shared/schema/settings/system.json`，格式与插件的页面级设置完全相同（`06-plugins.md` §11.1）。设备端代码一律按这些 key 读取，**不要把阈值和开关写死在代码里**；默认值与现有实现一致。

声明可带分类 `sections: [{id,label,icon?}]`，字段用 `section` 归类；分类顺序取自数组。`icon` 只引用已登记的单色矢量名，根分类和横屏侧栏显示同一组24dp图标，文字间距16dp、行高不变；全有或全无，不画占位。图标平时为次要文字色，侧栏选中时为强调文字色，位置随RTL镜像并跟随根层红移滤镜。插件自有设置字段、高级页和其它操作链接不加图标。字段层级 `normal`、`advanced`、`hidden`，旧布尔 `hidden` 仍接受但不能与 `level` 并用。`depends` 由 OS 根据同一范围的生效值计算，收起时保留值。插件可用 manifest 的 `related` 关联可见、非敏感系统键，仅由设置管理员显示和编辑，不向该插件授予系统权限。

位置设置（ADR-021）包含 `location.mode/name/latitude/longitude/elevation/timezone/search_url`。自动模式的坐标来自设备时区的代表城市，界面明确说明精度；地点选择器可搜索城市、区县并显示行政层级，始终提供离线手填入口。选中地点以一次原子设置提交切换到手动模式。查询中、无结果、失败及数据来源均有本地化文案；搜索 URL 也由此 schema 管理。

`time` 沿用API10，值为ASCII `HH:mm`，24小时制、5分钟一档。原生编辑先改草稿，取消、返回、Home或离页均不提交，确定只发一次提交；开始与结束允许跨午夜，不能相等。迁移逐 `local` / `server` 层处理：合法新trigger优先同层旧值，否则旧关→`off`、旧开→`sun`，随后消费该层旧bool，保留本地优先级，重置新值后不重复迁移。

显示分类公开变暗时间/无人变暗，时长档位分别为30/60/120/300/600秒和60/180/300/600/1800秒；高级公开退出ENGAGED及切换ambient角色的时间。系统分类的应用自动返回用0/300/900/1800/3600秒，0显示本地化“关闭”；合法非档位值照常显示。其余传感器阈值、坐标、缓存、网络/Server和边缘调节项继续隐藏。

- 跨字段约束（两对 lux 阈值）违反时拒绝写入并提示原因
- 变化立即生效：主题阈值与注意力计时由策略对象在下一次采样时读取新值，方向与亮度立即应用；主题切换按 §1 的 2 秒颜色插值过渡
- **不在设备设置里**的东西：页面顺序、首页两栈放哪些卡片、安装哪些插件、照片集——它们是部署配置，由 Server 管理（`06-plugins.md` §8、§12）

## 10. 设置页（`form` 版式）

设置页是 `settings` 插件的页面（`06-plugins.md` §11.3），版式 `form` 由 OS 提供，样式遵循本文其它章节（token、字号、间距、夜间滤镜都自动生效）。

设置行只显示标签和当前值。分组以留白区分，不画分隔线、状态圆点或选项箭头；仅 `link` 行显示换页箭头。

- 竖屏单列，左右各20dp，内容最大宽560dp。提供form.nav且可用宽度≥700dp时，左侧240dp分类、24dp间距、右侧最多560dp内容，两栏各自滚动；RTL镜像。分类名18sp单行，选中用强调文字色；标题32sp Medium，右侧“完成”热区≥48dp
- 最小行高 56dp；分组标题 14sp 次文字色；行标签 18sp，最多两行；右侧当前值 14sp 次文字色，占用不超过可用文字区域的一半，过长省略。内置字段没有 `help`；旧第三方字段继续显示以兼容 API 1–8。`warn` 仅在布尔开关启用时显示一句，`placeholder` 仅在文本编辑框显示；无障碍描述包含当前可见提示
- 控件：
  - `bool` → 开关（52×32dp），点整行切换；无障碍节点提供开关角色与选中状态
  - `choice` → 行尾仅显示当前值，点击后**就地展开**选项列表（不弹对话框），选中即收起
  - `number` → 默认只显示标签和描述器生成的当前值，点击才展开。有 `presets` 时展开内联单选；其余展开滑块及两侧 48dp 的 −/+ 按钮。与 choice 共用展开项，一次只开一项。横向拖动在松手时提交，纵向起手交给页面滚动，取消手势恢复已提交值。亮度描述器带 OS 计算的 `preview: brightness`，拖动直接临时预览设备亮度；取消、收起或离页恢复保存值，预览不写设置。其他数字不预览设备能力。稳定值和拖动数值共用描述器的本地化格式，不由 View 拼另一份单位。`format: duration` 的秒数显示为秒、分钟或小时，0 可用 `zero` 指定“关闭”；档位不限制其它合法下发值
  - `text` → 行尾显示值（过长截断，`secret` 显示为 ••••）；点击进入编辑，若设备没有输入法则为只读（见 `06-plugins.md` §11.3）
  - `time` → 行尾显示 `HH:mm`；进入原生时刻编辑，小时每次1小时、分钟每次5分钟，32sp数值、18sp标签与按钮，无键盘、秒数或AM/PM；取消不提交，确定提交一次
- 页面底部仅在本页有修改时显示“恢复默认”。该 link 带确认文字，确认后清除此页的设备修改；取消不变。地点及其坐标、海拔、时区相关六项一起重置
- 提交失败时控件回弹到原值，并在该行下方用 `warnText` 色显示一行原因，3 秒后以 120ms 淡出；系统关闭动画时直接清除。再次失败重新计时，成功修改、重置、切换设置作用域、离开页面或切换语言均取消旧提示计时，避免旧回调干扰新页面
- 入口：长按页面或卡片（反馈见§5）进入所属插件设置，自有字段或`related`任一非空即有页；无设置页时进入系统根分类。根页按schema顺序显示“显示、模式、位置与单位、桌面、媒体与投屏、系统、插件”，插件分类动态列列表。分类和插件页只列常用项，末尾有高级项时才显示“高级”；插件页顶部为关联的系统字段，末尾“系统设置”回根分类。磁贴和投屏直达各自设置，投屏行的设置入口也进入投屏范围
- 退出：完成、Home或30秒无操作退出整个设置会话；Back先关选择器/展开项，再逐层退高级、分类与插件栈，根页才退出。保持ENGAGED，原生输入框打字和按键均算操作；Home丢弃草稿。恢复默认只影响当前显示字段，关联系统行按system范围处理，地点连同六个键清除
- 两栏切换分类会替换当前选择，不增加返回层；高级和插件页继续入栈。由系统根页进入横屏时默认显示第一类；转为竖屏保留当前分类/层级并恢复分类列表的返回层。直接长按插件仍以该插件作为退出边界
- 行数有限（以系统 schema 为准，插件 ≤ 32 项），直接创建全部行；城市与时区搜索结果用原生列表复用行

## 磁贴（API 4 / ADR-025）

固定网格横屏 8×6、竖屏 6×8（ADR-028，取代最初的 6×4 / 4×6）；外边距 20dp，间距 8dp，磁贴直角 0dp，内边距 12dp（small 8dp）。单元由短边决定（本机约 69dp），网格贴长边远端，余下约 142dp 为标题栏。尺寸 small/medium/wide/large 对应 1×1/2×2/4×2/4×4，内容密度由 OS 固定。背景按引用 color > tile color > accent，前景白字优先（白字对比度 <4.55 才用黑字），颜色变化按 Motion.NUMBER 插值，不重建 View。夜间根层滤镜统一处理。系统设置 tiles.live 默认 true，tiles.interval 默认 8 秒（5–60、步长 1），tiles.background 为 indigo / teal / wine（默认 indigo），各语言同名字段由 shared schema 生成。

用户补充（2026-10-31）：以 Windows Phone / Windows 8.1 的 Metro 磁贴为参照。磁贴必须直角、平面、无阴影；网格基础单元保持正方形；信息以大号轻字重数字为主、标签锚定底部起始侧、纯色留白，不沿用普通圆角卡片的排版。RTL 镜像网格和内容。参考微软 [Windows Phone 设计建议](https://blogs.windows.com/windowsdeveloper/2013/01/18/8-tips-for-designing-windows-phone-apps/) 与 [Windows/Phone 8.1 磁贴模板目录](https://learn.microsoft.com/en-us/previous-versions/windows/apps/hh761491(v=win.10))。使用现有 Android 字体，不分发 Segoe。当前沿用 Windows 8.1 的垂直 peek 方向，不采用 Phone 的 3D 翻转。

**开始屏（ADR-028）**：磁贴页永远是深色，不跟随明暗主题。背景是 OS 固定的深色对角渐变加两道极淡的光带（靛蓝 #1E1B4B→#3730A3、深青 #042F3D→#0E5A66、酒红 #2E0A24→#6B1244），只绘制一次。标题栏里 OS 以 Roboto Thin 绘制页面标题（32sp，随语言重新翻译，RTL 在右侧）。

排版（dp，内边距之内）：名称与详情 14sp，照片标题 18sp；数值只从 14、18、32、72sp 预设档中选择，small 不超过 32sp。放不下时省略，不连续缩小。图标与网格尺寸沿用 ADR-028；图片使用全幅背景和照片上的底部遮罩，名称栏不随翻面滑动。

**动画**：按下倾斜（最大 7°、缩到 96.5%、90ms 减速进入，松手 300ms 过冲回弹）；打开页面时每张磁贴 380ms 升起（缩放 .9→1、上移 26dp、透明度 0→1），按声明顺序每张延迟 38ms，上限 380ms；页面由手指拖入时不重复。插件可请求 pulse（放大到 108% 再过冲回弹）、flip、nudge（±10dp 衰减抖动，360ms），详见 `06-plugins.md` §6.9。系统关闭动画时全部直接跳到终点。

真机发现夜间红色矩阵会压低中灰底的对比度。磁贴按合成后的颜色选择黑白前景；两者都低于 4.5:1 时，仅在夜间把底色向最近的可读亮/暗端补偿。浅色/深色完全保留插件底色；夜间仍经过统一根层滤镜。


## 原生 Aero 桌面（API 5 / ADR-026）

`aero` 是独立的固定 OS 版式。原创蓝色丝带桌面、玻璃窗口双边线、高光、微小景深、52dp 底部任务栏与原生开始菜单构成整体。窗口 5dp 圆角只用于 Aero；tiles 一律 0dp。桌面与玻璃通过缓存的 Canvas 渐变绘制，不实时模糊。原生模拟钟、天气和完整照片来自普通 widget 引用，横竖屏自动重排；菜单和任务栏均有实际导航，保留所属插件长按设置与横向翻页。

防残影微移不移动全屏背景：Aero 壁纸与任务栏底板固定贴边，只移动窗口、标题、菜单及任务栏前景；tiles 背景同样固定，只移动磁贴内容。切页预览和重新布局保留前景偏移，不能因整页平移露出底层背景。

窗口标题、菜单与时间日期跟随系统语言/格式；夜间标题按合成后颜色选前景。此版式不增加插件外观选项，现有 ambient/sleep/home 角色继续沿用。设计与来源见 `25-windows-design.md`。

## 11. 界面文字（ADR-044）

1. 只写这是什么、当前异常状态、能做什么，不解释原理。
2. 设置只有标签和当前值；格式要求放输入框占位符，输错由校验报错；有风险的布尔开关打开后显示一句 warn。
3. 正常状态不显示提示。异常只说结果，不说原因链。
4. 空状态一句：没有什么，或下一步做什么。
5. 不用“请”“您”“你”和感叹号；单句结尾不加句号。
6. 使用 DLNA、AirPlay、Miracast、Wi-Fi、设备管理等通用名称，不造词。
7. zh-Hans 设置标签最多 12 字，其它界面文字最多 20 字，不用换行凑长度；诊断正文、署名和许可声明例外。
8. 同一列表的图标全相同时不画图标；同一信息一屏只出现一次。
9. 不用中圆点、Emoji、斜体、眉标、章节编号、全大写小标题或状态小标签。同一行几个值用两个空格，地名用逗号或顿号。密码掩码保留。

Aero、时钟表盘、照片/视频遮罩、字幕、署名和法律声明的例外见 ADR-044；Aero 的文字也须四档字号且不用中圆点。新界面默认没有说明文字。

## 12. 安卓应用网格（ADR-045）

原生`grid`按可用宽度每96dp一列，至少3列，由OS决定列数。单元最小96dp高，上下各8dp、左右各4dp内边距；图标56dp，名称与图标间距8dp，名称14sp居中、单行省略。单元使用与设置行相同的水波纹，不加边框、分隔线或角标。RTL由原生GridView镜像。图片沿用OS图片权限与生命周期，回收时停止旧请求，不显示上一项的图标。

“安卓应用”磁贴底色为`#107C10`，标题与正文颜色仍由OS决定。网格正常时底部无说明文字，空状态只有“没有安卓应用”。grid页面覆盖呼吸圆，磁贴页与其它应用的返回规则不变。尺寸和列数没有插件参数；设备18项是否需要滚动及各语言省略情况在APP-5证据中记录。

广播从`tiles.apps`的磁贴进入。`radio.stations`使用focus版式和原生tabs/list，分电台/收藏；`radio.now`使用已有nowplaying和原生控制，显示台名、ICY曲名及收藏操作。没有内置电台，不新增组件、样式参数或播放通道。返回后继续播放，操作栏控制同一媒体会话；地址、名称和断线重试间隔走插件设置。功能证据见`artifacts/app/APP-3/`。


## 13. 全系统边缘导航（ADR-046）

物理左缘右滑返回，底缘上滑到home首页并清空返回栈，顶缘下拉同一个控制栏；全系统不显示安卓通知/快捷设置和导航栏。操作栏的应用按钮仍去launcher应用磁贴页，和回首页分开。中文排版优先。旧nav.back_enabled/nav.up_enabled是隐藏兼容项，全局模式必须保留必要的返回/首页出口。外部窗口不获取焦点、不暂停视频。实际模块联动未验时不宣称全局已完成，见38-global-gestures.md。

控制栏六个快捷入口按3列×2行排列：Wi-Fi、静音、红移、睡眠、设置、应用。红移用 `sunset`，睡眠用 `moon`；两者为手动模式切换，关闭回白天，保持时间取 `mode.manual_hold`。字号与其它快捷入口一致，不加说明文字；网格由OS决定，不开放行列参数。
